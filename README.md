# Schedule Bot - Бот расписания ВГЛТУ

Простой Telegram-бот для просмотра расписания группы НТТС2-261-ОС. Без AI, только расписание с удобными кнопками.

## Структура проекта

```
WorkDevin/
├── src/                    # Исходный код
│   ├── schedule_bot.py    # Основной бот
│   └── parser.py          # Парсер расписания (опционально)
├── data/                   # Данные
│   ├── schedule.json      # Расписание
│   └── preloaded_schedule.json  # Предзагруженное расписание (старый бот)
├── config/                 # Конфигурация
│   ├── requirements.txt   # Зависимости
│   └── .env.example       # Пример переменных окружения
├── runtime.txt             # Версия Python (обязательно для Render)
├── README.md              # Документация
└── .gitignore             # Git ignore
```

## Возможности

**Команды:**
- `/start` - показать главное меню с кнопками
- `/menu` - вернуться в главное меню
- `/today` - расписание на сегодня
- `/tomorrow` - расписание на завтра
- `/week` - расписание на текущую неделю
- `/date` - показать календарь для выбора даты
- `/update` - обновить расписание (только для админа)

**Кнопки:**
- 📅 **Сегодня** - расписание на текущий день
- 📆 **Завтра** - расписание на следующий день
- 🗓 **Выбрать дату** - открыть календарь (выбор месяца → выбор дня)
- 📊 **На неделю** - расписание на всю неделю

## Установка и запуск

### Локально

1. Установите зависимости:
```bash
pip install -r config/requirements.txt
```

2. Создайте файл `.env` в корне проекта:
```
TELEGRAM_TOKEN=your_telegram_bot_token
ADMIN_ID=your_telegram_user_id
```

3. Запустите бота:
```bash
python src/schedule_bot.py
```

### Развертывание на Render

1. Создайте Web Service на Render
2. Подключите GitHub репозиторий
3. Настройки:
   - **Runtime**: Python
   - **Build Command**: `pip install -r config/requirements.txt`
   - **Start Command**: `python src/schedule_bot.py`
4. Переменные окружения:
   - `TELEGRAM_TOKEN` - токен бота от @BotFather
   - `ADMIN_ID` - ваш Telegram ID (для команды /update)

## Обновление расписания

Расписание хранится в файле `data/schedule.json`. Есть два способа обновления:

**Способ 1: Ручное редактирование**
- Откройте `data/schedule.json` в редакторе
- Измените или добавьте даты и пары
- Коммитните изменения в GitHub
- Render автоматически redeploy

**Способ 2: Автоматический парсинг с сайта**
- Установите зависимости локально:
  ```bash
  pip install selenium webdriver-manager
  ```
- Запустите парсер:
  ```bash
  python src/parser.py
  ```
- Скрипт откроет сайт ВГЛТУ, введёт группу и сохранит расписание в `data/schedule.json`
- Загрузите обновлённый файл в GitHub

## Формат schedule.json

```json
{
  "2026-10-20": [
    {
      "time": "13:40-15:10",
      "subject": "Физическая культура",
      "room": "са/Гл",
      "teacher": "Шестаков Ф.Ф."
    }
  ]
}
```

## Примечания

- Сайт ВГЛТУ не предоставляет публичного API, поэтому парсинг через Selenium
- Парсер требует установки Chrome и драйверов
- Для регулярного обновления можно настроить GitHub Actions или cron-задачу
